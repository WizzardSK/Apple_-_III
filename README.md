# Apple_-_III

Thumbnails for Apple III software, laid out as [libretro-thumbnails](https://github.com/libretro-thumbnails), named after the MAME short names, as the MAME `apple3` software list has them.

Snaps, titles from AntoPISA's [progetto-SNAPS MAME Software List Resources](https://www.progettosnaps.net/softwareresources/).
