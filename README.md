# Apple_-_III

Thumbnails for Apple III software, laid out as [libretro-thumbnails](https://github.com/libretro-thumbnails), named after the MAME short names, as the MAME `apple3` software list has them.

Snaps, titles from AntoPISA's [progetto-SNAPS MAME Software List Resources](https://www.progettosnaps.net/softwareresources/), scaled to 4:3 (560x420): the Apple III draws 560x192 with tall pixels, and the snaps are taken at that size, so they came out squashed.
